HOW IT WORKS (7-STEP WORKFLOW)
================================================================================

When you run: python main.py --jax-file jax.py --pytorch-file pytorch.py ...

1. VALIDATE FILES
   - Checks that both module files exist

2. ANALYZE MODULES (LLM-Powered)
   - Reads module code
   - Sends to Qwen LLM with smart prompts
   - LLM identifies:
     * Input shapes and dimensions
     * Output shapes
     * Critical parameters
     * Edge cases to test

3. GENERATE TEST CASES
   - Creates ~40-50 test inputs based on analysis
   - Includes: random inputs, edge cases (zeros, ones, extremes)
   - Multiple batch sizes and input shapes
   - Saves for reproducibility

4. LOAD MODULES
   - Dynamically imports JAX module class
   - Dynamically imports PyTorch module class
   - Instantiates both

5. RUN TESTS
   - For each test case:
     * Run forward pass on PyTorch module
     * Run forward pass on JAX module
     * Compare outputs
     * Track differences

6. ANALYZE RESULTS (LLM)
   - Qwen LLM analyzes:
     * Which tests passed/failed
     * Pattern of differences
     * Likely causes
     * Recommendations for fixes

7. GENERATE REPORT
   - Creates JSON report with:
     * Summary statistics
     * Detailed test results
     * LLM analysis
     * Actionable recommendations

================================================================================
5 KEY COMPONENTS EXPLAINED
================================================================================

1. MODULE ANALYZER (module_analyzer.py)
   Purpose: Use LLM to understand your modules

   What it does:
   - Reads JAX module code
   - Reads PyTorch module code
   - Sends to Qwen LLM with analysis prompts
   - LLM returns structured analysis:
     * Input shapes to test
     * Output shapes expected
     * Critical parameters
     * Edge cases
   - Compares both analyses
   - Creates unified test strategy

   Output: Test configuration tailored to your modules

2. TEST CASE GENERATOR (test_case_generator.py)
   Purpose: Create intelligent test inputs

   What it does:
   - Generates random inputs of various shapes
   - Creates edge case inputs (zeros, ones, extremes)
   - Varies batch sizes (1, 2, 4, 8...)
   - Saves all test cases to disk
   - Provides metadata about tests

   Output: 40-50 test inputs + metadata

3. MODULE TESTER (module_tester.py)
   Purpose: Run modules and compare outputs

   What it does:
   - Dynamically loads module files
   - Instantiates module classes
   - For each test:
     * Converts input to PyTorch tensor
     * Runs PyTorch module
     * Converts input to JAX array
     * Runs JAX module
     * Compares outputs:
       - Check shapes match
       - Calculate absolute difference
       - Calculate relative difference
       - Check against tolerance

   Output: Detailed comparison results

4. PARITY AGENT (parity_agent.py)
   Purpose: Orchestrate entire workflow

   What it does:
   - Coordinates all 3 components above
   - Validates input files
   - Calls analyzer → test generator → tester
   - Gets LLM analysis of results
   - Generates final report
   - Saves all outputs

   Output: Complete parity report

5. LLM CLIENT (llm_client.py)
   Purpose: Communicate with Qwen API

   What it does:
   - Makes API calls to Qwen LLM
   - Handles authentication
   - Parses JSON responses
   - Supports custom prompts
   - Tests connection

HOW TO USE IT
================================================================================

STEP 1: Update Config
  Edit config.py:
  LLM_CONFIG["api_key"] = "your_qwen_api_key"

STEP 2: Run Parity Check
  Option A (CLI):
    python main.py \
      --jax-file /path/to/module_jax.py \
      --pytorch-file /path/to/module_pytorch.py \
      --jax-class MyModuleJAX \
      --pytorch-class MyModulePyTorch

  Option B (Python):
    from agents.parity_agent import ParityAgent

    agent = ParityAgent(verbose=True)
    results = agent.run_parity_check(
        jax_file="module_jax.py",
        pytorch_file="module_pytorch.py",
        jax_class_name="MyModuleJAX",
        pytorch_class_name="MyModulePyTorch"
    )

STEP 3: Review Results
  Open parity_results/parity_report.json
  Read LLM analysis and recommendations
  Fix any issues identified

STEP 4: Re-run (Optional)
  After making fixes, run again to verify

CONFIGURATION OPTIONS
================================================================================

In config.py you can customize:

1. LLM Settings:
   - API endpoint
   - Model name (Qwen/Qwen3-32B)
   - Max tokens (1000)
   - Temperature (0.7)

2. Test Parameters:
   - Batch sizes: [1, 2, 4]
   - Input shapes: [(3, 32, 32), (1, 64, 64)]
   - Num test cases per config: 3-5
   - Absolute tolerance: 1e-4
   - Relative tolerance: 1e-3

3. Framework Settings:
   - Verbose output
   - Save reports
   - Report directory
